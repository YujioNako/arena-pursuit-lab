# 逐域 · 斗牛对抗训练实验室

纯浏览器可运行项目，无需安装 npm 依赖。需要 Node.js 18 或以上提供本地 HTTP 服务。

```sh
git clone https://github.com/YujioNako/arena-pursuit-lab.git
cd arena-pursuit-lab
node server.mjs
```

打开 http://127.0.0.1:4173 。不能直接双击 HTML：ES 模块及后台 Worker 需要 HTTP。

## 使用

1. 选择双网络自我对抗，或者斗牛白痴化的恒速追逐 / 锁向直冲。
2. 设置训练代数与种子，点击「开始训练」。训练期间可回放已完成对局。
3. 播放速度可选 0.5×–64×；「直达结果」跳到结局；「连续演示」自动生成下一局。仅改变播放速度，物理步长不变。
4. 「运行 8 局独立测试」使用额外种子；图表显示每代固定留出场景成绩。
5. 在对局档案中回放任何训练候选、测试或演示。
6. 实验会自动保存在浏览器 IndexedDB；JSON 导出包含双方权重、所有已完成对局及曲线，导入后可以继续训练。

## 数学约定

- 场地半径 25 m，角与斗牛士均为点；30 s 内距离严格小于 0.4 m 则捕获。
- 斗牛士速度 0–3 m/s，瞬时变向；斗牛速度 0–8 m/s。
- 斗牛最小转弯半径 R(v)=v，因此移动时最大角速度 1 rad/s。允许直行与较大半径。
- 原题未定义的约定：零速也限 1 rad/s；速度无加速度限制；硬边界取消越界位移，不反弹；控制周期 0.1 s。
- 物理步长 0.01 s，圆弧积分，步内相对线段扫掠捕获；弧线近似误差约 0.0001 m。
- 初始点均匀采样于半径 20 m 内，间距至少 8 m，初始速度为零。

## 训练与评分

双方各为 14–16–3 tanh MLP，291 参数；输入完全可观测状态，输出速度与目标朝向。默认监督模仿追逃规则初始化，可取消并随机重置。随后推理完全由网络执行，没有隐藏的启发式动作覆盖。

训练采用交替进化搜索（不是 PPO）：对一方权重进行成对高斯扰动，在相同场景上比较当前策略与候选，保留最优策略；下一代切换一方。白痴化模式只更新斗牛士。所有评估对局保留策略权重与种子，可复现。

捕获时牛分数为 70 + 30 × (1 − t/30)；否则为 30 × (1 − d_min/50)。斗牛士得分为 100 − 牛分数。评分不是胜率。固定的 8 个测试场景不参与优化；额外测试使用另一套种子。

这是轻量实验基线，不保证收敛或证明最优策略。长期大量训练会占用浏览器内存和存储；可导出后开启新的浏览器实验环境。页面关闭后训练停止。

## 文件

- dist/engine.js：确定性运动模型、网络、监督初始化、评分。
- dist/worker.js：后台训练、测试与完整逐局记录。
- dist/app.js：界面、回放、曲线、持久化及导入导出。
- dist/index.html / style.css：中文响应式界面。
- tests.mjs：约束、严格阈值、扫掠碰撞、固定策略与复现测试。

运行验证：`node tests.mjs`。

后台训练验证：`node tests-worker.mjs`。可双击 `start.cmd` 启动本地服务。

## GitHub Pages

推送到 `main` 后，GitHub Actions 先运行语法检查、物理测试与后台训练测试，全部通过后将 `dist/` 部署到 GitHub Pages。

首次配置：仓库 **Settings → Pages → Source → GitHub Actions**。也可在 Actions 中手动运行 **Verify and deploy Pages**。

站点完全在访问者自己的浏览器中计算，无后端、API 密钥或第三方依赖。每位访问者的训练档案存于自己的浏览器；换域名或设备需要先导出、再导入实验 JSON。本地浏览器档案不会随源码部署。

运行完整验证：`npm test`。`.openai/` 是本地历史托管配置，不纳入公开仓库。
