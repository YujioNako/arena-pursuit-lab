# 逐域 · 斗牛对抗训练实验室

[在线实验室](https://yujionako.github.io/arena-pursuit-lab/) · [自动验证与部署](https://github.com/YujioNako/arena-pursuit-lab/actions/workflows/pages.yml)

纯浏览器可运行项目，无需安装 npm 依赖。需要 Node.js 18 或以上提供本地 HTTP 服务。

```sh
git clone https://github.com/YujioNako/arena-pursuit-lab.git
cd arena-pursuit-lab
node server.mjs
```

打开 http://127.0.0.1:4173 。不能直接双击 HTML：ES 模块及后台 Worker 需要 HTTP。

## 使用

1. 选择双网络自我对抗，或者斗牛白痴化的恒速追逐 / 锁向直冲。
2. 设置训练代数与种子，点击「开始训练」。训练期间可回放已完成对局。
3. 播放速度可选 0.5×–64×；「直达结果」跳到结局；「连续演示」自动生成下一局。仅改变播放速度，物理步长不变。
4. 「运行固定基准 + 随机测试」同时运行固定对手基准及额外随机对局；图表显示三条分别可比较的胜率曲线。
5. 在对局档案中回放任何训练候选、测试或演示。
6. 实验会自动保存在浏览器 IndexedDB；JSON 导出包含双方权重、所有已完成对局及曲线，导入后可以继续训练。

## 数学约定

- 场地半径 25 m，角与斗牛士均为点；30 s 内距离严格小于 0.4 m 则捕获。
- 斗牛士速度 0–3 m/s，瞬时变向；斗牛速度 0–8 m/s。
- 斗牛最小转弯半径 R(v)=v，因此移动时最大角速度 1 rad/s。允许直行与较大半径。
- 原题未定义的约定：零速也限 1 rad/s；速度无加速度限制；硬边界取消越界位移，不反弹；控制周期 0.1 s。
- 物理步长 0.01 s，圆弧积分，步内相对线段扫掠捕获；弧线近似误差约 0.0001 m。
- 初始点均匀采样于半径 20 m 内，间距至少 8 m，初始速度为零。

## 训练与评分

双方各为 14–16–3 tanh MLP，291 参数；输入完全可观测状态，输出速度与目标朝向。双方都显式接收当前距离 d / 50（第 13 项输入，10 Hz 更新）；已有输入保持维数不变，旧权重可兼容。默认监督模仿追逃规则初始化，可取消并随机重置。随后推理完全由网络执行，没有隐藏的启发式动作覆盖。

V2 使用带验证的排序进化策略（不是 PPO）。每代轮换一方，默认在 16 个随机场景中混合当前、初始及最多 6 个历史对手；斗牛士还对抗 8 m/s 恒速直接追逐。汇总 4 对扰动的排名，生成受限范数的更新，不再直接采用单个最高分扰动。σ 默认 0.02，并随尝试次数衰减。白痴化只更新斗牛士，训练及防退步验证始终使用所选规则与固定速度。

提议必须同时改善至少 24 个新场景的平均训练奖励、胜局数不下降，并通过独立的 48 场固定对手防退步验证（胜局数不下降、训练奖励下降不超过 0.25）。否则完整保留原权重。防退步验证参与选权，不称为独立测试；固定样本保护不保证在任意未知场景都不退步。历史对手、初始化基准、衰减计数随存档保留，导入后可确定性续训。

回放兼容评分保持不变：捕获时牛分数为 70 + 30 × (1 − t/30)；否则为 30 × (1 − d_min/50)，斗牛士得分为 100 − 牛分数。该分数不直接用于 V2 优化。

训练过程量 P 为 exp(−距离/5) 的时间平均值（10 Hz 采样并按真实持续时间积分）。牛奖励 = 100×捕获 + 25×(1−t/30) + 10P + 5exp(−d_min/3) − 3×顶墙秒数/30；斗牛士奖励 = 100×存活 + 25t/30 + 5(1−P) − 3×顶墙秒数/30。胜负占主要权重，并由额外验证的胜局条件保护；这些过程奖励不意味着已知最优策略。

每代固定 8 个当前双方测试起点，轮换自动回放；训练起点逐代变化。每 10 代、训练结束以及手动评估时，分别报告各 64 个固定留出场景中的「斗牛捕获初始斗牛士」「斗牛士逃脱初始斗牛」「斗牛士逃脱规则斗牛」。三条曲线均越高越好、不要求合计 100%。这些留出种子不参与选权，额外随机测试又使用另一套种子。白痴化下，规则基准遵循所选模式与速度，斗牛网络基准显示被冻结网络的能力。

V2 自动读取旧版实验，保留全部权重和逐局回放，并提示旧策略可能已退化。建议导出旧实验后，使用规则模仿初始化重置并重新训练。新存档按权重去重，所有真实评估对局仍可回放；旧版程序不能读取 V2 压缩文件。

## 500 代学习验证

默认参数、训练种子 42 和 43，各训练 500 代，再在 200 个未用于训练、选权或界面报告的相同起点上评估。可复现结果与源文件 SHA-256 记录在 [learning-validation.json](learning-validation.json)。

| 指标 | 种子 42：训练前 → 500 代 | 种子 43：训练前 → 500 代 |
| --- | --- | --- |
| 牛对初始斗牛士捕获率 | 81.5% → 96.5% | 73% → 98% |
| 斗牛士对初始斗牛存活率 | 18.5% → 22.5% | 27% → 31% |
| 斗牛士对直接追逐存活率 | 54.5% → 53.5% | 49% → 56% |

接受更新分别为 17/500、24/500；并非每代都有通过验证的改进。结果支持这两次运行没有出现旧版的整体退化，但斗牛士提升有限，种子 42 的规则基准下降 1 个百分点。不要把当前双方的零和分数当成能力提升，也不保证所有种子或更长训练都能单调提高。

```sh
npm test                                  # 快速物理、训练/恢复、回放兼容性验证
npm run benchmark -- 42 500 result-42.json # 真实 Worker，500 代 + 新场景评估
npm run test:learning                      # 两个种子完整 500 代学习回归（数分钟）
```

这是轻量实验基线，不保证收敛或证明最优策略。长期大量训练会占用浏览器内存和存储；可导出后开启新的浏览器实验环境。页面关闭后训练停止。

## 文件

- dist/engine.js：确定性运动模型、网络、监督初始化、评分。
- dist/worker.js：后台任务、测试与完整逐局记录。
- dist/trainer.js：混合对手、排序聚合、验证门槛与独立能力基准。
- dist/experiment.js：权重去重存储、旧版兼容与压缩存档恢复。
- dist/app.js：界面、回放、曲线、持久化及导入导出。
- dist/index.html / style.css：中文响应式界面。
- tests.mjs：约束、严格阈值、扫掠碰撞、固定策略与复现测试。

运行验证：`node tests.mjs`。

后台训练验证：`node tests-worker.mjs`。可双击 `start.cmd` 启动本地服务。

## GitHub Pages

推送到 `main` 后，GitHub Actions 先运行语法检查、物理测试、后台训练测试及两个种子的完整 500 代学习回归，全部通过后将 `dist/` 部署到 GitHub Pages。

首次配置：仓库 **Settings → Pages → Source → GitHub Actions**。也可在 Actions 中手动运行 **Verify and deploy Pages**。

站点完全在访问者自己的浏览器中计算，无后端、API 密钥或第三方依赖。每位访问者的训练档案存于自己的浏览器；换域名或设备需要先导出、再导入实验 JSON。本地浏览器档案不会随源码部署。

运行完整验证：`npm test`。`.openai/` 是本地历史托管配置，不纳入公开仓库。
